# ✦ Carta Mágica para Maibelyn ✦

> *Un sitio web interactivo con temática de magia y encantamientos para sorprender a alguien muy especial.*

---

## 📌 Sobre el Proyecto

Este proyecto es una experiencia web interactiva diseñada para presentar una carta especial. Combina animaciones CSS, un sistema de cuenta regresiva, efectos visuales de partículas e interacción por contraseña ("encantamiento").

### ✨ Características Principales
* ⏳ **Cuenta Regresiva Activa:** Desbloqueo automático al llegar a una fecha específica.
* 🔑 **Sistema de Desbloqueo por Clave:** Acceso anticipado mediante una palabra secreta (*Expecto Patronum*).
* 🌌 **Fondo Animado Interactiva:** Sistema de partículas mágicas generado con `Canvas` en Javascript.
* 📜 **Diseño de Carta Antigua:** Tarjeta desplegable estilo pergamino con sello de cera en 3D.
* 📱 **Totalmente Responsive:** Adaptado para una experiencia óptima tanto en móviles como en computadoras.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica del sitio.
* **CSS3:** Animaciones, transformaciones 3D, gradientes y diseño adaptativo.
* **JavaScript (ES6):** Lógica de tiempo, partículas en canvas, almacenamiento local (`localStorage`) y validación de clave.
* **Google Fonts:** Tipografías temáticas (*Cinzel*, *Cormorant Garamond* y *Great Vibes*).
